# FRYGO Owner Demo v3

Premium owner-presentation version of the FRYGO restaurant website concept.

## What is optimized
- Light, food-first visual system
- Strong restaurant-style hero and CTA hierarchy
- Mobile-first responsive navigation
- Menu search + category filtering
- Cart interaction with WhatsApp-ready order flow
- Deals/promotions showcase
- Location/contact section ready for verified details
- Lightweight CSS food illustrations instead of heavy image assets
- No invented phone, address, ratings, reviews, prices or business history

## Before launch
Replace the verified placeholders/config in `src/App.jsx` with:
- FRYGO logo
- real food photography
- real menu names/descriptions
- prices
- WhatsApp and phone
- exact address + Google Maps URL
- opening hours
- social links
- actual promotions/deals

## Run
npm install
npm run dev

## Production
npm run build
npm run preview
